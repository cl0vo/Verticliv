# Vertical Studio 0.18

Основной режим программы — монтаж вертикальных видео. Старый Brainrot и публикация доступны через «Ещё: Brainrot / публикация».

## Быстрый результат

1. Перетащи видео в окно. Поддерживаются форматы, которые способен прочитать установленный FFmpeg (включая MP4, MKV, MOV, WebM).
2. Укажи начало и конец. По умолчанию выбран первый фрагмент до 60 секунд. Для длинного исходника можно выбрать любую часть или нажать «Всё видео».
3. Выбери «Весь кадр + размытие», чтобы сохранить содержимое кадра, или «Заполнить 9:16». При необходимости выдели нужную область мышью.
4. Оставь субтитры включёнными и нажми «Создать вертикалку». Программа распознает выбранный фрагмент и сохранит MP4 1080×1920, H.264, 30 fps со звуком и отдельный SRT.
5. Для проверки текста до экспорта нажми «Распознать выбранный фрагмент». В таблице можно исправить слова и тайминги, добавить и удалить строки. Рыжим отмечаются слова с низкой уверенностью распознавания. Для полностью ручного текста нажми «Использовать таблицу без повторного распознавания». При расширении фрагмента экспорт сохраняет уже исправленные слова.

## Дота / стримы

- Выбери «Игра + вебка сверху».
- В переключателе под исходником выбери «Выделять веб-камеру» и обведи её в кадре.
- Затем выбери «Выделять основной кадр / игру» и обведи нужную часть игрового изображения.
- Настрой высоту вебки (15–50%). В каждом блоке выбранная область заполняет его с обрезкой по центру; результат сразу виден справа. Если важно сохранить HUD целиком, используй компоновку «Весь кадр + размытие».
- Словарь Dota 2 подсказывает распознавателю термины. Можно дописать свои ники и названия героев.
- Вкладка «Хайлайты» предлагает непересекающиеся фрагменты по пикам звука. Нажатие на кандидат выставляет границы клипа и момент зума. Включи зум, если он нужен; он приближает всю композицию на 12% на 1,2 секунды.

Поиск хайлайтов не анализирует игровые события, счётчик убийств или качество драки. Музыка и громкие эффекты тоже могут попасть в кандидаты. Автослежения за героем/лицом и смыслового монтажа в этой версии нет.

## Распознавание речи

Используется открытая библиотека [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (MIT) и модели Whisper. Чужие приложения не копировались; библиотека подключена как зависимость.

- Small — стартовый вариант для CPU; Medium и Large v3 требуют больше памяти и времени; Turbo — ещё один вариант модели.
- Русский, английский или автоопределение языка.
- VAD отсекает участки без речи; распознавание возвращает тайминги слов.
- Первый запуск скачивает выбранную модель с Hugging Face, поэтому нужен интернет и свободное место. После кэширования доступна локальная работа. Исходное видео не отправляется в облачный сервис распознавания.
- CPU работает без CUDA. NVIDIA требует совместимые CUDA 12 и cuDNN 9; если их нет, выбери CPU.
- Игровой звук, музыка, одновременная речь и никнеймы могут ухудшить точность. Проверяй текст перед публикацией.
- На этапе скачивания/загрузки модели отмена ожидает завершения загрузки. Во время распознавания она проверяется между сегментами; экспорт FFmpeg прерывается оперативно.

## Проекты и просмотр

«Сохранить проект» записывает JSON: путь к исходнику, области, границы, настройки и исправленные слова. Само видео в проект не копируется. При переносе исходника редактор предложит найти его заново.

Справа работает быстрый геометрический предпросмотр. Шрифт, подсветка слов и размытие могут немного отличаться от итогового FFmpeg-рендера. «Тест 5 сек» создаёт точный короткий MP4 от начала выбранного фрагмента.

Выходной файл заменяется только после успешного рендера и проверки размера/длительности. Исходник перезаписать нельзя. Для длинного видео требуется место под временный звук (примерно 58 МБ/час для поиска хайлайтов и 115 МБ/час для распознавания).

## Запуск из исходников

Python 3.11+, FFmpeg и FFprobe в PATH:

```sh
pip install .
arara-factory
```

Windows-сборка включает FFmpeg и библиотеки распознавания; веса Whisper загружаются при первом использовании. Сборка ветки разработки создаёт артефакты Actions, но не публикует автоматическое обновление основного приложения.
