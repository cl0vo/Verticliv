# Verticliv: запись → готовая подборка

План от 27 сентября 2026. Это целевой продукт, а не список уже реализованных функций.

Актуальное решение пользователя: закончить локальную программу без смыслового AI-отбора. Подключение облачного API и загрузка отдельной языковой модели отложены; этап 2 ниже — только возможное будущее развитие. Приоритет 0.20.1: сплошная компоновка вебка/игра с сохранением пропорций, шаблоны субтитров и проверенный локальный экспорт. Заполнение двух блоков до краёв неизбежно обрезает часть исходника; фактическая обрезка показана в предпросмотре, режим сохранения областей целиком доступен отдельно.

## Главное обещание

Пользователь добавляет локальную запись, выбирает тип материала и нажимает одну кнопку. Получает небольшую подборку законченных вертикальных роликов с читабельными субтитрами, понятным началом и концом, сохранённым важным содержимым кадра. Количество — верхняя граница, а не обязательная норма: три хороших эпизода лучше десяти случайных. Обещания вирусности нет.

Программа общего назначения для Windows. Возможности компьютера влияют на скорость/режим обработки, а не зашиваются в логику продукта. Twitch, наблюдение за папкой и автопубликация не являются обязательными для основного сценария.

## Конвейер

1. **Проверка записи:** дорожки голоса/игры, ориентация, переменная частота кадров, повреждения, свободное место. Исходник не изменяется.
2. **Анализ один раз:** расшифровка с таймингами, паузы, сцены и низкочастотные кадры для анализа. Кэш переживает перезапуск и меняется при изменении исходника или настроек анализа.
3. **Кандидаты:** границы законченных реплик/эпизодов, контекст перед событием, развязка после. Громкость — дополнительный сигнал, а не определение интересности.
4. **Отбор:** оценка понятности без предыдущих минут, наличия события/мысли, законченности, разнообразия. Для игр — дополнительно визуальное событие и реакция, не только текст. Модель возвращает ссылки на реальные таймкоды; выдуманные события и выход за запись отклоняются.
5. **Монтаж:** разные профили «Разговор», «Игра + камера», «Экран/обучение». Безопасный весь кадр при неуверенном определении областей. Не обрезать карту, интерфейс или демонстрацию ради заполнения 9:16. Удаление пауз с контекстом, без обрезания слов; зум только обоснованный.
6. **Оформление:** редактируемые субтитры с подсветкой, защищённые зоны интерфейса платформ, нормализация звука, отключаемые баннер и фирменный стиль. Обложка и заголовок должны соответствовать реальному содержанию.
7. **Проверка и выдача:** техническая валидация каждого файла, предупреждения о речи/кадрировании, сетка роликов с быстрыми действиями «Оставить», «Переделать», «Убрать». MP4 + SRT + проект + таймкод источника. Публикация — отдельное подтверждаемое действие.

## Порядок разработки

### Этап 1 — границы и воспроизводимость

Добавить режим полной расшифровки с кэшем, выбор по границам реплик вместо фиксированных окон, подавление повторов и словарь имён/терминов. Сохранить быстрый режим звуковых реакций как явно обозначенную эвристику. Не называть эвристическую оценку смысловым AI-анализом. Проверить короткие и длинные русскоязычные записи, тишину, музыку, смену исходника, отмену и повторный запуск.

### Этап 2 — настоящий отбор эпизодов

Сделать независимый интерфейс смыслового ранжирования по расшифровке и выборочным кадрам. Локальная модель и опциональный внешний сервис должны работать через один контракт. До внешнего сервиса отдельно согласовать передачу текста/кадров и бюджет; не включать платные запросы по умолчанию. При недоступности модели честно показывать ограниченный режим, а не подменять смысл громкостью.

### Этап 3 — визуальное качество

Определение сцен/говорящего, плавное кадрирование, отдельный профиль игрового поля и камеры, предпросмотр на реальном мобильном размере. Раздельный выбор аудиодорожки микрофона OBS. Обоснованное удаление пауз. Никаких универсальных агрессивных центральных кропов для игр.

### Этап 4 — надёжный продукт

Постоянные задания с возобновлением по этапам, история и повторный рендер без нового распознавания, пакетная проверка результатов, обновления с сохранением данных. Автопапка — дополнительный режим, только после стабилизации основного сценария. Автопубликация — позднее, отдельно от генерации.

## Открытые компоненты: кандидаты, не установленные обещания

- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) — уже используется; распознавание, тайминги слов, VAD. MIT.
- [WhisperX](https://github.com/m-bain/whisperX) — кандидат для более точного выравнивания слов; оценить дополнительный вес зависимостей и поддержку русского перед заменой текущего движка. Проверять лицензии выбранных моделей отдельно от кода.
- [PySceneDetect](https://github.com/Breakthrough/PySceneDetect) — кандидат для смен сцен, не для понимания игрового события. BSD-3-Clause.
- [ClipsAI](https://github.com/ClipsAI/clipsai) — MIT, пример сегментации по расшифровке и кадрирования говорящего. По документации ориентирован на разговорный, повествовательный контент. Не готовая основа игрового автонарезчика без проверки.
- [Auto-Editor](https://github.com/WyattBlue/auto-editor) — пример удаления пауз и монтажных отступов. Репозиторий Unlicense; состав лицензий готовых бинарных сборок проверять отдельно. Удаление тишины само по себе не находит лучшие моменты.

При фактическом включении стороннего кода закреплять версию, сохранять LICENSE/NOTICE и проверять зависимости. На данном этапе новые перечисленные библиотеки не копируются в приложение автоматически.

## Как принимать качество

Собрать контрольный набор с разрешения владельцев: разговор, Hearthstone с камерой, динамическая игра, демонстрация экрана, запись телефона. На каждом отметить вручную удачные эпизоды. Сравнить текущий поиск по громкости и новый режим на одинаковом материале.

Целевые критерии, которые ещё нужно измерить: не менее 70% первых пяти предложенных роликов пригодны без перемонтажа; нет обрезанных слов/потерянных развязок; нет дублирующихся эпизодов; важные области видны; субтитры проверяемы и исправимы. Любая технически невалидная выдача блокируется. Сохранять результаты измерений, а не считать прохождение unit-тестов доказательством интересности ролика.

## Текущее состояние

База умеет локальную пакетную нарезку, Whisper-субтитры, экспорт 1080×1920 и ручную правку. В версии 0.20.0 добавлен первый этап: эвристический отбор по границам реплик, кэш полной расшифровки, словарь, пропуск начала/конца, профили материала и локальная страница просмотра. Это не смысловое понимание видео. На локальной игровой записи с малым количеством речи режим реплик отказался выдумывать речевые клипы; режим реакций создал два проверенных технически ролика по 25 секунд. Речевой путь проверен дополнительно на синтетическом озвученном материале, а не выдан за проверку реального редакторского качества. Ручной Twitch-импорт подготовлен отдельно; скачивание и развитие интеграции отложены по решению пользователя. Черновик журнала автопапки пока не подключён к интерфейсу и не является работающей фоновой автоматизацией.
