# Verticliv

Личная Windows-программа для монтажа вертикальных видео, ARARA Reels и публикации Shorts. Репозиторий: [cl0vo/Verticliv](https://github.com/cl0vo/Verticliv).

Основной режим **«Автонарезка»**: несколько исходников → подборка клипов → Whisper-субтитры → MP4 1080×1920.

1. Перетащи несколько видео или добавь папку (без вложенных папок).
2. Выбери профиль материала, ориентир длины 10–180 секунд и до 12 клипов с каждого исходника. При необходимости пропусти заставку/конец и добавь имена или термины в словарь речи.
3. Нажми «Создать подборку». Готовые MP4, SRT, TXT, редактируемые `.verticliv.json`, локальная страница просмотра и отчёт появятся в отдельной папке запуска.
4. Двойной клик открывает клип; «Править выбранный клип» открывает его исходник и тайминги в ручном редакторе.

Автокомпоновка сохраняет весь горизонтальный кадр на размытом фоне, вертикальные исходники заполняют 9:16. Можно явно выбрать другой способ. **Оба режима отбора пока эвристические, не смысловой AI-анализ.** «Реплики и паузы» распознаёт выбранную часть целиком, выбирает окна по границам реплик и подавляет похожие фрагменты; длина может отличаться от ориентира. «Звуковые реакции» быстрее, ищет пики звука и подходит как первый просмотр игровых записей. В режиме реакций при тишине используются равномерные фрагменты с предупреждением; режим речи при отсутствии подходящей речи сообщает об этом, не выдумывая клипы. Ошибка одного исходника не прерывает остальные. Отмена сохраняет готовые клипы и частичный отчёт. Автонарезка ничего не публикует сама.

### Игра и вебка — отдельными блоками

Для игрового материала используй профиль «Игра / Hearthstone» и кнопку «Настроить области игры и вебки». В редакторе выдели вебку, переключи режим выделения на игру и выдели игровую область. Проверь вертикальный предпросмотр, затем нажми «Применить игру и вебку к подборке». Шаблон сохраняется для следующих записей с тем же расположением элементов; записи с другими пропорциями потребуют настройки заново.

Основная игровая компоновка помещает вебку сверху, игру снизу и оставляет отдельную полосу под субтитры. Каждая выделенная область сохраняется целиком, без автоматического центрального обрезания. Вариант «заполнение с обрезкой» оставлен отдельно для осознанного выбора. Если вебка уже закрывает игру в исходнике, скрытые пиксели не восстанавливаются: выбрать игровую область без вебки можно только за счёт исключения этой части исходника. Для полного чистого игрового поля нужен соответствующий исходный материал.

Распознавание Small + CPU int8, последовательная обработка и повторное использование модели. Экспорт пробует NVIDIA NVENC и при недоступности возвращается к CPU. Первый запуск распознавания требует интернета для загрузки модели, само видео на сервис распознавания не отправляется. Полная расшифровка длинной записи может занять значительное время. Она кэшируется в `.verticliv-cache` внутри выбранной папки результатов; изменение исходника, модели, языка, диапазона или словаря создаёт новую запись кэша. Кэш содержит текст речи — это локальные пользовательские данные, не исходники проекта.

- Выбор областей игры и вебки мышью, предпросмотр 9:16.
- Обрезка длинных записей по времени, сохранение проектов.
- Редактируемые субтитры, подсветка слов, экспорт SRT.
- Кандидаты хайлайтов по пикам звука и настраиваемый момент зума.
- Старый Brainrot и публикация доступны как дополнительные функции.

## Направление развития

[План полноценного автонарезчика](docs/PRODUCT_PLAN_RU.md): отбор законченных эпизодов, анализ текста и кадров, подходящий монтаж для разных видов материала и проверка качества. Twitch отложен; основной сценарий — локальная запись. Автопапка ещё не включена в интерфейс. Не путать план развития с уже реализованными функциями.

## Режим ARARA / Brainrot

Личная Windows-программа для сборки вертикальных ARARA Reels.

## Как пользоваться

1. Скачать артефакт `Verticliv-Installer` из последней успешной [сборки GitHub Actions](https://github.com/cl0vo/Verticliv/actions).
2. Запустить `Verticliv-Setup.exe` и установить программу.
3. Открыть Verticliv через ярлык на рабочем столе, перейти в «Ручной редактор» и выбрать «Ещё: Brainrot / публикация».
4. Один раз выбрать PNG-шаблон ARARA в настройках.
5. Перетащить в верхний блок новый Reel со звуком.
6. Перетащить в нижний блок длинный brainrot-файл.
7. Нажать `ТЕСТ 5 СЕКУНД`, затем `СОБРАТЬ ГОТОВЫЙ REEL`.

Программа запоминает длинный brainrot, шаблон и папку результата. Для каждого нового Reel обычно достаточно заменить только верхнее видео.

## Что делает программа

- берёт неповторяющийся фрагмент из длинного brainrot-видео;
- не создаёт сотни промежуточных MP4;
- сохраняет звук только из основного Reel;
- накладывает Hero-шаблон ARARA;
- зацикливает прозрачный анимированный баннер `arara777` в верхней части ролика;
- создаёт субтитры в стиле CapCut;
- использует сбалансированный NVIDIA NVENC P4 для GTX 970 и при проблеме переключается на CPU;
- проверяет 9:16, звук, FPS и длительность до добавления файла в очередь;
- ставит большой просроченный хвост на паузу, восстанавливает интервалы и повторяет ошибки по одной;
- сохраняет результат в выбранную папку; по умолчанию для новых настроек — `Видео/Verticliv/renders`;
- включает FFmpeg и FFprobe внутрь Windows-сборки.

## Артефакты сборки

- `Verticliv-Installer` — обычный установщик Windows с ярлыком и удалением через системные настройки.
- `Verticliv-Portable` — переносной EXE `Verticliv.exe` без установки.

## Обновление с ARARA Factory / Vertical Studio

Verticliv продолжает существующий проект. Установщик обновляет прежнюю установку, не создавая отдельную копию; папка уже установленной программы может сохранить старое имя. Выбранные папки видео и настройки не сбрасываются.

Для совместимости настройки Windows остаются в пространстве `ARARA / ARARA Factory`, а очередь, журнал и зашифрованные токены — в `%LOCALAPPDATA%\ARARA Factory`. Это служебные имена: переименовывать или удалять эти папки вручную не нужно. Подключение YouTube и история публикаций сохраняются.

Новые проекты редактора сохраняются как `*.verticliv.json`; старые `*.vertical.json` и JSON-проекты также открываются. Внутренний Python-пакет `arara_factory` сохранён для совместимости, новая команда запуска — `verticliv`.

## Личная настройка

Если в репозитории присутствует `assets/arara_template.png`, шаблон автоматически включается в EXE и его не требуется выбирать вручную. Без этого файла программа попросит указать PNG один раз и запомнит путь.
