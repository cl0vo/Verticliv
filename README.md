# ARARA Factory

Личная Windows-программа для сборки вертикальных ARARA Reels.

## Как пользоваться

1. Скачать артефакт `ARARA-Factory-Installer` из последней успешной сборки GitHub Actions.
2. Запустить `ARARA-Factory-Setup.exe` и установить программу.
3. Открыть ARARA Factory через ярлык на рабочем столе.
4. Один раз выбрать PNG-шаблон ARARA в настройках.
5. Перетащить в верхний блок новый Reel со звуком.
6. Перетащить в нижний блок длинный brainrot-файл.
7. Нажать `ТЕСТ 5 СЕКУНД`, затем `СОБРАТЬ ГОТОВЫЙ REEL`.

Программа запоминает длинный brainrot, шаблон и папку результата. Для каждого нового Reel обычно достаточно заменить только верхнее видео.

## Что делает программа

- берёт неповторяющийся фрагмент из длинного brainrot-видео;
- не создаёт сотни промежуточных MP4;
- сохраняет звук только из основного Reel;
- накладывает Hero-шаблон ARARA;
- зацикливает прозрачный анимированный баннер `arara777` в верхней части ролика;
- создаёт субтитры в стиле CapCut;
- использует сбалансированный NVIDIA NVENC P4 для GTX 970 и при проблеме переключается на CPU;
- проверяет 9:16, звук, FPS и длительность до добавления файла в очередь;
- ставит большой просроченный хвост на паузу, восстанавливает интервалы и повторяет ошибки по одной;
- сохраняет результат в `Видео/ARARA Factory/renders`;
- включает FFmpeg и FFprobe внутрь Windows-сборки.

## Артефакты сборки

- `ARARA-Factory-Installer` — обычный установщик Windows с ярлыком и удалением через системные настройки.
- `ARARA-Factory-Portable` — переносной EXE без установки.

## Личная настройка

Если в репозитории присутствует `assets/arara_template.png`, шаблон автоматически включается в EXE и его не требуется выбирать вручную. Без этого файла программа попросит указать PNG один раз и запомнит путь.
